# Oil Spill Incidents: HSE & Environmental Compliance Analysis

## Project Overview
This project analyzes reported oil spill incidents to support Health, Safety, and Environmental (HSE) compliance and regulatory oversight. The goal is to identify incident patterns, environmental risk factors, and response effectiveness using publicly available spill data.

Rather than focusing on operational prevention, this analysis reflects the type of monitoring and risk assessment conducted by petroleum regulatory agencies.

## Stakeholders
- Health, Safety & Environmental (HSE) regulators
- Environmental compliance officers
- Policy and enforcement teams
- Public interest and environmental monitoring organizations

## Key Questions
- Where and when do oil spill incidents occur most frequently?
- Which facilities or regions represent higher environmental risk?
- What are the most common contributing factors to spills?
- Which spills have the greatest environmental impact?
- How effective are cleanup and response efforts over time?

## Data Source
The primary dataset used in this project is a publicly available oil spill incidents database containing reported spill events, facility information, location details, contributing factors, material types, quantities, and cleanup timelines.

## Tools
- SQL for data querying and aggregation
- Power BI for visualization and dashboarding
- Python for data cleaning and exploratory analysis
