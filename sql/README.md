# SQL Analysis Plan

This folder contains SQL queries used to analyze oil spill incident data in support of HSE and environmental compliance oversight.

## Analysis Questions

The following questions guide the SQL analysis:

1. How many oil spill incidents occur over time (monthly and annually)?
2. Which facilities experience repeat spill incidents?
3. How are spill incidents distributed across regions?
4. What contributing factors are most commonly associated with spills?
5. Which incidents involve the largest reported quantities of spilled material?
6. Which spills have the highest environmental impact?
7. How long do spill cleanup and response efforts typically take?

Queries will be added incrementally as the analysis progresses.
